# Philad Info Bot

Телеграм-бот з оголошеннями церкви: події, домашні групи, розклад, потреба в служінні, пожертвування та анкета «Давай знайомитись».

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписати BOT_TOKEN і ADMIN_CHAT_ID
.venv/bin/python -m bot
```

## Налаштування групи адмінів

1. Додайте бота в групу адмінів.
2. Надішліть у групі `/chat_id` — бот відповість ID (виду `-100…`).
3. Впишіть його в `.env` як `ADMIN_CHAT_ID` і перезапустіть бота.
4. У групі надішліть `/help` — там уся інструкція.

Команди приймаються **лише** з цієї групи. Туди ж приходять заповнені анкети.

## Керування контентом

Розділи: `welcome`, `events`, `homegroups`, `schedule`, `serving`, `donations`, `meet`.

Надішліть у групу фото з підписом (або просто текст), потім дайте на нього відповідь (reply):

| Команда | Дія |
|---|---|
| `/set events` | замінити фото і текст |
| `/set_text events` | лише текст (або `/set_text events Текст…`) |
| `/set_photo events` | лише фото |
| `/del_photo events` | прибрати фото |
| `/reset events` | повернути стандартний вміст |
| `/show events` | переглянути розділ |

Форматування Telegram (жирний, курсив, посилання) зберігається.

## Структура

```
bot/
  __main__.py      точка входу
  config.py        змінні оточення
  sections.py      список розділів і стандартні тексти
  db.py            SQLite (контент розділів, анкети)
  keyboards.py     inline-кнопки
  render.py        показ розділу (фото + текст)
  handlers/
    user.py        меню для користувачів
    form.py        анкета «Давай знайомитись»
    admin.py       команди для групи адмінів
```

Щоб додати новий розділ, допишіть його в `bot/sections.py` (і в `MENU_SECTIONS`, якщо він має бути кнопкою в меню).
